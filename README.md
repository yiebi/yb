问题定义:快捷生成自我介绍卡片，方便参赛者快速互相了解并找到契合的队友
核心功能：用户填写个人信息（昵称，技能，负责的技术栈及组队需求）
流程：打开网页-填写信息-实时预览名片-保存图片
技术实现：技术栈 前端HTML+CSS+JavaScript，
运行方式 浏览器本地运行&GitHub线上部署运行，
数据设计 仅保存在浏览器内存中
边界与风险：1 问题-项目采用了CSS等过渡动画新特性，部分低版本浏览器不兼容，可能导致样式错乱
             处理方法-采用渐进兼容设计，若浏览器不支持毛玻璃效果，则自动降级为普通透明卡片，保证正常使用
           2 问题-移动端屏幕不适配，导致布局挤压错乱
             处理方法-使用媒体查询自动识别屏幕尺寸，使页面自适应屏幕
           3 问题-用户输入内容过长，卡片文字超出边界
             处理方法-限制文字数量并提示，同时让文字自动换行，使内容排版贴合名片
迭代方向：  1 高优先级-用户使用体验 添加本地存储功能，用户刷新页面之前填写的信息不会丢失
             可能代价：增加微量维护成本同时代码及占用内存增加
           2 中优先级-美观度 新增多种颜色及背景选择，更具个性化
             可能代价：文件体积增大，新增多种CSS样式，需写切换逻辑
